# Architecture

This document records decisions and the state of what exists. See the root README for the full principles.

## Backend (implemented foundation)

- **Modular monolith.** One Django project (`backend/config`) with domain apps under `backend/apps/`. Only `accounts` exists. `backend/common` holds cross-cutting code (currently the health endpoint).
- **Database.** PostgreSQL with PostGIS via GeoDjango (`django.contrib.gis.db.backends.postgis`). Tests also run on PostGIS; SQLite is not used.
- **Settings.** `base`, `development`, `production`, `test`. Everything comes from environment variables. Production validates mandatory variables at import and enables HTTPS and cookie hardening; development may fall back to a random secret key.
- **Time.** Stored in UTC (`TIME_ZONE = "UTC"`, `USE_TZ = True`). `PRODUCT_TIME_ZONE = "Asia/Kolkata"` is the initial display time zone, applied when rendering for users.
- **User model.** `accounts.User`: UUID primary key, email as the login identifier (stripped and lowercased, case-insensitive unique), no username. `AbstractBaseUser` + `PermissionsMixin` was chosen over `AbstractUser` to avoid carrying an unused username field. The custom model was created before the first migration, because changing `AUTH_USER_MODEL` later is costly.
- **API.** DRF with URL-path versioning (`/api/v1/`). Authentication is required by default; public endpoints opt out explicitly. OpenAPI is generated by drf-spectacular (`/api/schema/`, `/api/docs/`, `/api/redoc/`).
- **Health.** `GET /api/v1/health/` reports application, database and PostGIS status with `200` or `503`. It exposes no configuration. Redis is not reported because it is not integrated.

## Authentication (decided, not implemented)

- **Web:** secure HttpOnly cookies with CSRF protection.
- **Mobile:** short-lived access tokens and rotating refresh tokens kept in Expo SecureStore, with refresh tokens revoked on logout or security events.
- Both clients share the same Django authentication and authorisation rules. Credentials never go in `localStorage` or `AsyncStorage`.

## Contracts

The backend OpenAPI schema is the source for `@roomsync/contracts`. TypeScript generation (`openapi-typescript`) has not been set up.

## Known environment notes

GeoDjango needs the GDAL and GEOS shared libraries on the host. GDAL older than 3.9 triggers Django check `gis.W001`; prefer 3.9 or newer.
