# backend

The RoomSync Django backend.

**Planned:** A Django modular monolith using Django REST Framework, GeoDjango and drf-spectacular, backed by PostgreSQL/PostGIS, with Redis and Celery for background work. The backend owns all business logic.

**Layout:**

- `config/settings/`: project settings (planned).
- `apps/`: domain apps, starting with `accounts` (planned).
- `tests/`: backend tests (planned).

**Status:** Not yet implemented. Django has not been initialised; directories are placeholders.
